# 龍門電鍍機台畫面數據轉 PLC 記憶體位址 (Address) 對照指引

本文件整理自 **uPro DSM 電鍍製程自動化助手 (`percentagToAmp`)** 原先自機台人機監控軟體（`uPro DSM - Data Monitoring System`）畫面所擷取之各項製程、槽位與機台數據。

供自動化工程師於三菱 PLC（MELSEC-Q / iQ-R / FX 系列）開發環境（GX Works2 / GX Works3）中，快速尋找並對照對應之暫存器記憶體位址（Data Register `D`、Link Register `W`、內部繼電器 `M` 等）。

## 1. 已確認之 PLC 基準位址

專案在先前版本中，已由底層實測並確認之 PLC 點位如下，可作為周邊相關功能暫存器區段之基準點：

| 點位代碼 | 暫存器型態 | 位址 (Address) | 縮放倍率 (Scale) | 說明與用途 |
| :--- | :---: | :---: | :---: | :--- |

| **1000** | **加載槽號** | `[NAME:cmbLoadTankProcess]` | `INT16` | 槽號 (1~21) | 數值常為 `1`（對應 `001# 上下料槽`）。 |

| **1004** | **總面積** | `[NAME:numArea]` | `INT16` 或 `REAL` | $dm^2$ | 產品總電鍍面積；影響總輸出電流計算。 |

## 3. 群組二：機台全槽位生產追蹤矩陣 (SVID 1022)

現場機台為龍門電鍍線，包含約 **21 個槽位**（`001#` 到 `021#`）。原本程式透過掃描主畫面 DataGridView 讀取，在 PLC 中通常為連續之陣列結構（Data Block / Shift Register）：

| 槽位名稱 | 追蹤參數項目 | 原始對應欄位 | 建議 PLC 型態 | PLC 尋找建議與特徵 |
| :---: | :--- | :--- | :---: | :--- |
| **第 001 槽**<br/>(上下料槽) | 1. 當前資料編號 (料號)<br/>2. 當前批號 (Lot No)<br/>3. 當前片數 (數量) | DataGridView<br/>Col9 (料號)<br/>Col10 (批號)<br/>Col11 (片數) | `ASCII`<br/>`ASCII`<br/>`INT16` | **最關鍵驗證位址**。<br/>外掛軟體加載 Recipe 後，即是核對第 1 槽是否成功寫入該工單與料號。 |
| **第 002 ~ 008 槽**<br/>(前處理/水洗槽) | 1. 料號 / 2. 批號 / 3. 片數 | 同上 (Col9~11) | 同上 | 隨著天車移載，工單資料會在各槽位暫存器間**移位 (Shift/FIFO)**。 |
| **第 009 ~ 013 槽**<br/>(主電鍍反應槽) | 1. 料號 / 2. 批號 / 3. 片數<br/>**4. 在席/加工狀態** | 同上 (Col9~11) | 同上 +<br/>`Bit (M/Y)` | **機台運轉判斷位址**。<br/>原程式藉由檢查 9~13 槽有無物料來判定機台是否為 `RUN` 狀態。 |
| **第 014 ~ 021 槽**<br/>(後清洗/烘乾槽) | 1. 料號 / 2. 批號 / 3. 片數 | 同上 (Col9~11) | 同上 | 出站與清洗階段槽位資訊。 |

## 6. 三菱 PLC 記憶體尋找實務建議

1. **字串 (ASCII) 儲存特徵**：
   * 在 MELSEC-Q 系列中，ASCII 字串由連續的 16 位元暫存器（Word）組成。
   * **高低位元組順序 (Byte Order)**：1 個 Word 存放 2 個字元，通常 Low Byte 在前、High Byte 在後（例如字串 `"AB"` 在暫存器中值為十六進位 `0x4241`）。
2. **數值比例放大 (Fixed-point Scaling)**：
   * PLC 處理帶有小數點的數值（如電流密度 ASD、用水量、溫度）時，常以整數儲存並放大 10 倍或 100 倍，需注意小數點還原邏輯。
3. **槽位結構塊 (Data Block)**：
   * 電鍍線 21 個槽位通常會採用固定偏移量的結構體（例如每個槽位分配 50 個 Word，槽 1 為 `D2000~D2049`，槽 2 為 `D2050~D2099` 等），找到第一槽後即可推算後續槽位。
4. **比對 HMI Tag 標籤**：
   * 現場 WinForms 監控軟體必定也有與 PLC 連線的通訊模組，可比對該監控軟體的設定檔或變數表，即可快速確認確切之暫存器編號。
